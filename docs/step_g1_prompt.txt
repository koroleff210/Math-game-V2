OVERVIEW
--------
G1 adds the ability to create named groups of players and restrict Classic Mode
sessions to a specific group. It also adds admin CRUD for managing player accounts.

This is a pure foundation step: no game mechanics change, no new socket events,
no new game modes. All changes are in admin UI and access control.

When G1 is complete, an admin can:
  - Create, edit, delete student player accounts
  - Create groups, add/remove players from them
  - Create a Classic session restricted to a specific group
  - Players not in that group are blocked from joining (HTTP redirect + socket event)

  from app.extensions import db

STEP 8 — CLASSIC ROUTES: Group Access Check
--------------------------------------------
File: app/modes/classic/routes.py

Add helper (module level, before blueprint routes):

  def player_in_session_group(player, session):
      """Returns True if session is open (group_id is None) or player is a member."""
      if session.group_id is None:
          return True
      from app.models.groups import PlayerGroup
      group = db.session.get(PlayerGroup, session.group_id)
      if group is None:
          return True  # group deleted — treat as open
      return group.members.filter_by(id=player.id).first() is not None

Modify three existing HTTP routes (add check near top of each view function,
after the session lookup but before any render/redirect):

  /classic/play   (GET, classic_player_bp)
    After finding the waiting/active session:
      if not player_in_session_group(current_user, session_obj):
          flash('You are not enrolled in the group for this session.', 'danger')
          return redirect(url_for('player.dashboard'))  # or wherever is appropriate

  /classic/lobby/<id>   (GET, classic_player_bp)
    After loading the session:
      if not player_in_session_group(current_user, session_obj):
          flash('You are not enrolled in the group for this session.', 'danger')
          return redirect(url_for('player.dashboard'))

  /classic/game/<id>   (GET, classic_player_bp)
    After loading the session:
      if not player_in_session_group(current_user, session_obj):
          flash('You are not enrolled in the group for this session.', 'danger')

NOTE: If player.dashboard does not exist yet, redirect to url_for('auth.login') instead.
